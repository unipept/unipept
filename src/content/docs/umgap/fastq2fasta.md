---
title: umgap fastq2fasta
subtitle: Interleaves FASTQ files into a FASTA stream
---

The `umgap fastq2fasta` command takes one or more FASTQ files and interleaves them into a single FASTA file.

## Usage {#usage}

The FASTQ input files are given as command line arguments. In order, a single record is taken from each of these files,
and the record header and sequence are written to *standard output* in FASTA format, dropping the quality scores, until
any of the files runs out or records.

This command is generally used to combine two paired-end FASTQ files into a single FASTA file.
