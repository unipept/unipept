---
title: unipept pept2lca
subtitle: Returns the taxonomic lowest common ancestor for a given tryptic peptide.
---

The command reads peptides and links to [pept2prot](./pept2prot.md).

## Input {#input}

::: tip Input size
Keep the input small.
:::

::: code-group
```console [Arguments]
$ unipept pept2lca {{ not interpolated }}
peptide,taxon_id
```
```console [File]
$ unipept pept2lca -i input.txt
```
:::
